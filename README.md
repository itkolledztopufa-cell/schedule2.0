# Конструктор расписания · Академия ТОП

Статический HTML-инструмент для работы с расписанием колледжа. Не требует сервера или бэкенда — вся логика (подбор пар, проверка правил, сверка с Excel) считается прямо в браузере.

## Как разместить на GitHub Pages

1. Создайте новый репозиторий на GitHub (например, `raspisanie-top`). Можно приватный или публичный — Pages работает с обоими (для приватного репозитория нужен план GitHub Pro/Team/Enterprise, для публичного — бесплатно).
2. Загрузите файл `index.html` из этой папки в корень репозитория (кнопка **Add file → Upload files** в интерфейсе GitHub, либо через `git push`).
3. Зайдите в **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Source: Deploy from a branch**, ветку **main**, папку **/ (root)** → **Save**.
5. Через 1–2 минуты GitHub покажет ссылку вида:
   `https://<ваш-логин>.github.io/<имя-репозитория>/`
   Это и есть публичный адрес инструмента — открывается с любого устройства.

## Важно понимать про хранение данных

Это чисто клиентский инструмент: все добавленные консультации, перестановки пар и заблокированные слоты хранятся только в открытой вкладке браузера и **пропадают при перезагрузке страницы** или при открытии с другого устройства — это не общая база данных, а независимый расчёт на каждом устройстве.

Если позже понадобится, чтобы изменения сохранялись между сессиями или были видны всем одновременно, это отдельная задача (нужно либо сохранение в браузере, либо полноценный бэкенд с базой данных).
